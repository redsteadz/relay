# Security Policy

Relay handles communications, credentials, and provider actions. Do not open a public issue for a
suspected vulnerability or include real user data in any report.

Use GitHub private vulnerability reporting at
<https://github.com/redsteadz/relay/security/advisories/new>. Include affected commit, synthetic
reproduction, impact, and any known mitigation. Maintainers will acknowledge reports before
publishing disclosure timelines.

No production release exists yet. Security updates apply to current `main` once releases begin.
