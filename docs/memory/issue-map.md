# Issue Dependency Map

GitHub issue numbers will be added after repository creation. Milestone order is:

```text
M0 Foundation
  -> M1 Ingestion
    -> M2 Intelligence
      -> M3 Automations
        -> M4 Product Experience
          -> M5 Distribution and Compliance
```

Issue bodies remain authoritative for acceptance criteria and direct dependencies. This document
records cross-milestone structure only and must not mirror issue prose.
